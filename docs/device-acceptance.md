# A1.3 双平台真机验收清单

**本页不是实测报告。** 禁止用模拟器、图片回放、固定结果或单 ROI 探针代替完整链路验收。

| 证据 | 每个设备和档位必须记录 |
| --- | --- |
| 安装 | 构建版本和 SHA-256；真机型号/OS 或 Windows PC/OS；断网安装、首次启动、模型加载；Windows 另测卸载 |
| 工位 | Android 后摄 ID、系统指纹、分析视口；Windows UVC 符号链接、驱动、原生格式/尺寸/帧率、固定对焦和曝光参数 |
| 资产 | 权重、字典、预/后处理配置版本与哈希、运行库版本/架构、真值集版本 |
| 相机 | 权限、断流、重连、非对称靶标四角、横竖屏、触摸映射；Android AF 和 AE 分别记录触发、收敛、锁定、失效情况 |
| 业务 | 1 / 3 / 5 / 8 ROI 逐路采集比对；禁止 0 / 9 ROI 启动；验证暂停、停止、恢复、人工纠正、回放、CSV、日志；检查低置信/失败不伪造有效值 |
| 性能 | 1Hz 优先；单轮 P50/P95/P99；P95 ≤ 所选周期的 60%，80% 为单轮硬截止；2 小时丢拍率 < 1%，以计划拍点数为分母 |
| 识别质量 | 良好工况下自动接受读数的完整数值精确匹配率 ≥ 98%；同时报告覆盖率、待复核率、失败率，按设备和工况分层 |
| 稳定性 | 各支持组合连续 4 小时无崩溃、无异常断流且数据完整；记录内存、温升、降频、存储空间和重启结果 |

测试屏幕需覆盖数字位数、小数点、反光、频闪、熄屏和不同亮度。8 ROI 功能和 1Hz 性能独立判定；若 1Hz 未达标，只将用户显式选择且通过完整验收的 2s/5s 组合录入清单。锁定未知或未确认、权重缺失、单路未记录、未检测到目标 UVC、或未完成长时验证，都不得写入已通过档位。
