# A1.2 双平台设备验收清单

这里是待执行项目，不是实测报告。单 ROI「不入库」识别只用于定位模型契约、方向和画框问题；不能替代实际采集链路和性能验收。

## 每个设备组合必填

| 字段 | 记录 |
| --- | --- |
| Android 机型/OS，或 Windows PC/OS/相机型号和硬件 ID | 待填 |
| 相机后端、输入尺寸、帧率、实际格式和旋转 | 待填 |
| REC 模型/配置 SHA-256、训练数据版本、运行库、线程数 | 待填 |
| AF/AE 确认结果，或已复验的固定相机参数 | 待填 |
| 测试 ROI 数量与采样周期 | 1 / 3 / 5；1000 ms 优先 |
| 帧转换、裁剪预处理、REC、SQLite、UI、端到端 P50/P95 | 待测 |
| 超时和丢帧率、准确率、待复核率、失败率 | 待测 |
| 2h 内存、4h 连续运行、存储空间、恢复和导出 | 待测 |

1. 对齐预览和识别坐标。用非对称数字靶标覆盖四个角、各方向与两端不同分辨率，确认 ROI 取到正确设备。断开/重连后重做验证。
2. 用真实设备录入带真值样本，覆盖小数点、不同亮度、反光/频闪和屏幕熄灭；按设备及工况分别统计，不用演示数据计算准确率。
3. 分别压测 1、3、5 ROI；连续 4 小时验证不崩溃或异常断流。只对通过门槛的配置设置 ROI 上限及周期。若需降级，明确选择周期或减少 ROI，重新记录配置和测量结果。
4. 制造权限拒绝、相机断开/切后台、空间不足及未正常退出场景；确认不追加错误值，已持久化的数据可复核、回放并导出。
5. 安装正式包，在设备断网状态验证启动、数据库与 CSV；本工程不提供运行期模型下载，也不实现上传。
